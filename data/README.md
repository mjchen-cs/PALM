# Data

All data behind the figures and tables of the paper, in open formats (CSV, JSON, NumPy `.npz`).
They are regenerated by `python3 tools/export_data.py` and `python3 tools/export_offline.py`
after the experiments have been run.

## `raw/` - frame-by-frame time series of every online run (541 runs)
* `<EXP>.npz` (EXP = E1, E3, E5, E6, E6b, E7, E7b, E8, E11, E12, E13): compressed NumPy archive.
  For run `runNNNN`, the arrays `runNNNN/<series>` have one entry per frame:
  `Q` mean data queue per WD (kbit), `Y` mean virtual energy queue per WD, `E` mean WD power (W),
  `Ees` ES power (W), `wrate` delivered weighted rate (Mbps), `off` offloading ratio,
  `D` processed data rate of all WDs (Mbps), `hs` handshakes, `hpro` proactive handshakes,
  `dt` decision time (s, wall clock of the simulation machine).
  Per-device arrays (one entry per WD): `perdev_P` average power (W), `perdev_Jbit` energy per
  processed bit (J/bit), `perdev_off` offloading ratio, `perdev_D` processed data rate (Mbps),
  `Qfinal` final queues (kbit).
* `<EXP>_index.csv`: one row per run with the run id, the experiment tags (e.g., `lam`, `rekey`,
  `sec`, `xi`, `csi`, `T`), the seed, the scheme, the number of frames, and the cache key.
* `FORMAT.json`: the same description in machine-readable form.

Example:
```python
import numpy as np, pandas as pd
idx = pd.read_csv("data/raw/E1_index.csv")
z = np.load("data/raw/E1.npz")
rid = idx[(idx.scheme == "PALM-PS") & (idx.seed == 1)].run.iloc[0]
queue = z[f"{rid}/Q"]          # kbit, one value per frame
```

## `summary/` - steady-state summary of every run
`<EXP>.csv`: the index columns plus `ss_*` columns averaged over the last 30% of the frames
(`ss_Q`, `ss_E`, `ss_wrate`, `ss_off`, `ss_Ees`, `ss_hs`, `ss_hpro`, `ss_dt` (median), `ss_Qslope`).
The values in the paper are means of these columns over the seeds.

## `offline/`
* `E2_sic_order_gap.csv`: 400 power-allocation instances; per-method values (exact, greedy, SCA, ANNS,
  beta-order SCA, order search with and without budget), the upper bound, and the best value over
  all M! orders.
* `E9_partial_offloading.csv`: best binary versus partial-offloading DPP value (150 states).
* `E10_qaoa_simulation.json`: QAOA candidates in simulation (60 states, p = 1-3, noise levels).
* `S_states_allvals.npz`, `S_states_decisions.csv`, `S_params.json`: 200 sampled system states, the
  per-frame value of all 2^10 offloading vectors, and the decisions of PALM, greedy, and SCA.

## `timing/`
`xeon_solver_and_decision_times.json`: solver times versus M and decision times (median, 99th
percentile) versus N on one Xeon core, for all schemes.

## `hardware/`
* Jetson Orin Nano: `pqc_jetson_ap*.json` (PQC handshake times and energies, four runs),
  `local_compute.json` (GPU/CPU computing and DVFS), `profile_jetson_ap.json` (resulting profile),
  `jetson_decision_latency_{v2,rt,baselines}.json` and `bench_*.log` (controller decision latency).
* Origin Wukong 180: `instances.json` (QUBO instances), `results_WK_C180_p{1,2}.json` (hardware runs),
  `results_local_p1*.json` (simulator reference), `chip_info_WK_C180.json` (calibration of 21 Oct 2026).
